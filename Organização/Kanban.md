## Regras do Kanban

1. Cada tarefa deve possuir um responsável.
2. Uma tarefa só pode estar em uma coluna por vez.
3. Uma tarefa em desenvolvimento deve ser movida para **Em Andamento**.
4. Após o desenvolvimento, a tarefa deve ir para **Em Teste**, quando necessário.
5. Após a validação, a tarefa deve ser movida para **Concluído**.
6. O desenvolvimento do MVP possui prioridade sobre funcionalidades adicionais.
