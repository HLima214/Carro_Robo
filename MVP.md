# MVP — Carro Robô 4WD

## 1. Objetivo do MVP

O MVP (Minimum Viable Product) do projeto consiste em desenvolver uma versão minimamente funcional do carro robô capaz de realizar sua função principal: movimentar-se utilizando quatro rodas motorizadas.

O foco do MVP será implementar apenas as funcionalidades essenciais para que o carrinho funcione.

---

## 2. Quando o projeto estará minimamente funcional?

O projeto será considerado minimamente funcional quando possuir:

* Chassi montado;
* 4 motores DC instalados;
* 4 rodas instaladas;
* Bateria conectada;
* Arduino Uno R3 ou ESP32 instalado;
* Ponte H conectada aos motores;
* Controle básico dos motores.

O carrinho deverá ser capaz de:

* Avançar;
* Recuar;
* Virar para a esquerda;
* Virar para a direita;
* Parar.

### Critério de conclusão do MVP

O MVP estará concluído quando o carro robô conseguir movimentar-se corretamente utilizando os quatro motores e responder aos comandos básicos de movimentação.

---

## 3. Quando o projeto estará concluído?

O projeto será considerado concluído quando, além do MVP funcional, possuir:

* Carenagem instalada;
* Carenagem removível para manutenção;
* Componentes eletrônicos organizados;
* Bateria fixada corretamente;
* Cabeamento organizado;
* Teste de funcionamento dos quatro motores;
* Teste de tração;
* Teste de estabilidade;
* Teste térmico dos motores e drivers;
* Documentação técnica atualizada;
* Código e documentação organizados no GitHub.

---

## 4. Evolução do projeto

### Protótipo

Arduino/ESP32 → Ponte H → Motores

O objetivo do protótipo é testar a ideia e validar o funcionamento básico dos componentes.

### MVP

Chassi + 4 motores + 4 rodas + bateria + Arduino/ESP32 + Ponte H + controle básico.

### Produto final

MVP funcional + carenagem + organização dos componentes + testes finais + documentação completa.
